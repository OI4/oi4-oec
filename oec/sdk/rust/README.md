# Rust SDK D2 – Cargo workspace (P4, from C-046)

Workspace of the Rust SDK D2 (ADR-0011, ADR-0023, ADR-0026 proposed). The public API is the one decided in ADR-0020 (sketch in `sketch/`); the crates below grow with the P4 increments of `project/ROADMAP.md`.

| Path | Content | State |
|---|---|---|
| `oec-core/` | sans-IO protocol logic: Identification Link, dnp-encoding, Oi4Identifier (`il`), topic elements, allowed forms, Filter, topic parsing/building, subscription filters (`topic`) | increments 1–2 (C-046) |
| `oec/` | runtime and public API (ADR-0020) | from increment 4 |
| `oec-ffi/` | C ABI (ADR-0021) | P4 increment 8 |
| `sketch/` | P3 API sketch (not product code); deleted when `oec` exists | frozen |
| `spike/` | P3 spikes `schema-embed`, `mqtt-codec` (not product code) | frozen |

`sketch/` and `spike/` are stand-alone crates outside the workspace (`exclude`), with their own lock files.

## Rules

- Edition 2024, MSRV `rust-version = 1.89`, license MIT, `publish = false`.
- Lints for all members: `unsafe_code = "forbid"` (`oec-ffi` will opt out with a documented exception), `missing_docs`, clippy `all` + `pedantic` (warnings are errors in the check).
- `oec-core` has no runtime dependencies and no stability promise of its own; `oec` re-exports or wraps its types.
- Every rule cites its REQ ids in a doc comment; the walker in `sketch/tests/sketch.rs` checks that every cited id exists and is not deprecated.
- Acceptance test: the shared test vectors of the spec baseline, read from the JSON export `oec/spec/export/` (generated by `spectool render`), see `oec-core/tests/vectors.rs`.
- Supply chain: `Cargo.lock` is committed; `deny.toml` is the cargo-deny policy of ADR-0023 §2.

## Check

```sh
oec/sdk/check.sh   # part of oec/check.sh (step 5)
```

It runs `cargo fmt --check`, `cargo clippy --all-targets -D warnings`, `cargo test`, `cargo doc` (warnings are errors) and `cargo deny check`, all `--offline --locked` except the advisory DB fetch of cargo-deny (fallback: cached DB). cargo-deny is installed with `cargo install cargo-deny --locked`.
