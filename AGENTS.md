# AGENTS.md – Entry point for humans and AI agents

This workspace builds **OI4 Open Edge Computing (OEC) v2.0** artifacts from scratch:
JSON Schema, developer SDK/library (Rust core with Rust, C and Go front ends; Go binding = phase P4c, ADR-0027), three demo services with small Web UIs (weather, config, logger; P6 scope of the C-075 review), an OEC Registry, a micro SDK in C for microcontrollers (reference ESP32), two cross-platform compliance CLIs (application/messaging D7, infrastructure D8) and a Docusaurus documentation (written in the Community section of the guideline site, `oi4-oec-documentation/docs/community`, checked by `oec/docs`; C-100 addendum 2).

- All deployables live in the monorepo folder `oec/` (ADR-0012). The workspace root is a local git repo – commit every change individually, never push (ADR-0009/0012).
- Spec findings (`SF-xxx`) live only in `oi4-oec-documentation/findings/SPEC-FINDINGS.md` (since C-018; next free id there).
- One local gate for all code and data: `oec/check.sh` (spec checks, both schema validators, schema release freeze, oracle ↔ schema crosscheck, conformance tests; since C-041; 11 steps since C-104). Run it before every commit; it ends with "all checks passed". The GitHub Actions workflows in `.github/workflows/` are generated by `oec/ci` (`cd oec/ci && go run ./cmd/cigen`, never edited by hand; gate step 11, ADR-0032) and inactive until the PO pushes; `oec/ci/linux.sh` runs the gate job in an Ubuntu container (opt-in).
- `legacy/` is history only. Do not modify, do not copy code from it (see GUARDRAILS G-1.3).
- Who decides (GUARDRAILS G-3.4, amended 2026-10-26): the agent makes engineering decisions itself (layout, crates, APIs within accepted ADRs, libraries within the dependency policy, build/test setup, cycle cuts) and records them as ADRs `accepted (agent, G-3.4 b)`; the PO is asked for contradictions or missing definitions in the guideline (SF), guideline text, scope, phase order, languages, licenses and publication.
- Communication with the product owner: German. All project artifacts (logs, plans, code, docs): English.
