# ADR-0004 – MIT license for all new artifacts

- Status: accepted
- Date: 2026-10-12
- Deciders: product owner (Thomas), C-002

## Decision

All new artifacts (D1–D7) are licensed under **MIT**, consistent with the existing documentation repository and the legacy repositories.

## Consequences

- Dependencies must have MIT-compatible licenses (e.g. MIT, BSD, Apache-2.0, ISC); copyleft dependencies need product-owner approval.
- License report becomes part of the release (P9).
