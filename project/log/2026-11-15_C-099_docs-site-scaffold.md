## What was done

1. **Versions re-checked (A-492 → A-495).** `npm view` at the start: `@docusaurus/core` and `@docusaurus/preset-classic` 3.10.2 (4.0 only as canary), `react`/`react-dom` 19.3.1, `@mdx-js/react` 3.1.1, `clsx` 2.1.1, `prism-react-renderer` 2.4.1 – unchanged since C-098. Tools: node 22.13.0, npm 11.0.0.
2. **Scaffold in `oec/docs`** (ADR-0031 §1, amendment C-099):
   - `package.json` – `oec-docs` 0.1.0, private, MIT, `engines` node ≥ 22.12.0, scripts `build`, `serve`, `start`, seven exact dependencies, no devDependencies.
   - `package-lock.json` v3 – `npm install --package-lock-only --ignore-scripts --before=2026-10-27 --no-audit --no-fund`: 1275 packages, the tree of the C-098 survey.
   - `.npmrc` – as the registry Web UI: `registry=https://registry.npmjs.org/`, `save-exact`, `ignore-scripts=true`, `fund=false`, `audit=false`.
   - `docusaurus.config.mjs` – docs-only (`routeBasePath: '/'`, no pages plugin, `blog: false`, `sitemap: false`), `markdown.format: 'detect'`, every broken-link rule `throw`, no analytics and no search, navbar with the sidebar, dark footer with the MIT license (`oec/LICENSE`) and "© 2026 Open Industry 4.0 Alliance - Community", Prism with `bash`, colour mode by the system setting.
   - `sidebars.mjs` – one autogenerated sidebar (Getting started, Demo services with Logger, Weather and Config, OEC Registry, OEC Micro SDK).
   - `src/css/custom.css` – Infima colours only.
   - `src/remark/repoLinks.mjs` – the repository links (item 4).
   - `build.sh` – opt-in: `go test ./npmpolicy`, `npm ci --ignore-scripts --no-audit --no-fund`, `npm run build`, prints `docs: ok`.
3. **`"type": "module"` removed.** The first build failed in the server bundle with `require.resolveWeak is not a function`; without `"type": "module"` (the configuration files are `.mjs`) it builds. Re-locked: same 1275 packages.
4. **Repository links by a remark plugin (ADR-0031 §3 changed, A-497).** The function form of `markdown.hooks.onBrokenMarkdownLinks` (planned in C-098) only receives links to `.md`/`.mdx` files. `intro.md` also links `oec-ffi/include/oec.h` – Docusaurus would bundle it into the site as an asset – and the folder `oec-ffi/examples/`, which it reports as a broken link. The plugin `src/remark/repoLinks.mjs` runs in `beforeDefaultRemarkPlugins`, i.e. before Docusaurus resolves Markdown links and transforms file links (order checked in `@docusaurus/mdx-loader`), and rewrites a relative link or definition to `${OEC_DOCS_REPO_URL:-https://github.com/OI4/oi4-oec/blob/main}/oec/<path>[/]#<anchor>` if it resolves to an existing file or folder of `oec/` outside `oec/docs/`. Everything else is left to Docusaurus, whose rules are all `throw` (`onBrokenLinks`, `onBrokenAnchors`, `onDuplicateRoutes`, `markdown.hooks.onBrokenMarkdownLinks`, `onBrokenMarkdownImages`). The existence check was added after a probe (item 7) showed that a missing file of `oec/` was rewritten and built.
5. **npm policy `oec/docs/tools/npmpolicy`** (Go, standard library only; A-498). Modelled on `oec/registry/internal/uipolicy` (ADR-0029 §10), with the site rules of A-493 and the site-only licenses of ADR-0031 §5. What the real tree needed beyond the registry policy:
   - **prerelease versions** for six transitive packages (e.g. `@polka/url 1.0.0-next.29`, `cheerio 1.0.0-rc.12`, `infima 0.2.0-alpha.45`, `gensync 1.0.0-beta.2`); direct dependencies stay release versions;
   - **npm aliases** – `react-helmet-async` → `@slorber/react-helmet-async`, `react-loadable` → `@docusaurus/react-loadable` (both by Docusaurus; the lockfile `name` differs from the folder, the tarball URL uses the real name) – in a reviewed table;
   - **install scripts** – `core-js` (a funding message) and the optional darwin `fsevents` 2.3.3 (ships its prebuilt `fsevents.node`) – in a reviewed table; `ignore-scripts` keeps them from running;
   - **packages without a `license` field** – `eval` 0.1.8 and `format` 0.2.2 (MIT in the legacy `licenses` array), `require-like` 0.1.2 (MIT in its license file) – checked in `node_modules/` and listed with where the license is stated;
   - **OR rule** (A-493): `type-fest` ×2 `(MIT OR CC0-1.0)`, `opener` and `path-is-inside` `(WTFPL OR MIT)`, `rc` `(BSD-2-Clause OR MIT OR Apache-2.0)` pass on their allowlisted choice; `WITH` or a malformed expression fails;
   - **site-only licenses** (C-098 D-1 (a)): `tslib` 2.8.1 and 1.14.1 (0BSD), `mdn-data` 2.0.28 and 2.0.30 (CC0-1.0), `sax` 1.6.1 (BlueOak-1.0.0), `argparse` 2.0.1 (Python-2.0), `caniuse-lite` 1.0.30001819 (CC-BY-4.0);
   - `.npmrc` and the build rules of `docusaurus.config.mjs` (throw rules, no blog, no analytics/tag manager/search service, no guideline-site URL).
   A stale table entry (package gone, or a `license` field appeared) fails. Tests: `TestSite` (the committed site passes), `TestAllowed` (SPDX evaluator), `TestViolations` – **39 violations** on copies of the site files, each caught – and `TestMissingFiles` (4). The registry policy is unchanged and stays stricter (every OR term allowlisted, no site-only list).
6. **Gate step 10.** `oec/docs/check.sh` already ran `go test ./...` over `tools/`; the npm policy runs there without a script change. Header comments of `oec/docs/check.sh` and `oec/check.sh` and the READMEs (`oec/README.md`, `oec/docs/README.md`: layout, policy, build, `OEC_DOCS_REPO_URL`/`OEC_DOCS_URL`, updating the tree) describe it.
7. **Build and probes (A-499, A-500).** `rm -rf build .docusaurus node_modules && ./build.sh`: about 30 s, `docusaurus build` about 7 s, no broken link or anchor; `build/` 904 KB with 8 HTML pages (the 7 pages and 404), 17 JS files, 1 CSS file; `node_modules/` 306 MB.
