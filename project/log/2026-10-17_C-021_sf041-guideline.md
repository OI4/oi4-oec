- **REQ-IL-034:** the PO asks whether "in case of doubt" refers to an Identification Link that contains a scheme or a third-level domain; if so, it is fine.

Answer to the REQ-IL-034 question (agent): yes. The scheme (and port, path) is never part of the `ManufacturerUri` (MUST form of MG 4.3.1), so it is always dropped. "In case of doubt" concerns the host part: if the host of the Identification Link has a third-level domain (e.g. `id.provider.com` or `www.provider.com`), the `ManufacturerUri` is given as `<manufacturer>.<tld>` (`provider.com`). The guideline text stays as it is; REQ-IL-034 becomes `reviewed`.
