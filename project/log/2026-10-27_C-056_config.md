## Cycle cut (agent decision G-3.4 b, A-98)

**7b is not split.** The Config resource, its masking and the secret reload share one mechanism (the write path of 7a with `Handled::*` and a completion outside the lock) and one persistence pattern (the tables of 6a/7a). The masking applies to exactly the values `Set Config` changes, so splitting it off would leave a Config that leaks sensitive values on the bus. The secret reload is small (one function in the runtime, one in the core `Session`) and is the GL-ADR-022 part the prompt names.
- Size at the end: source +1989/−186 lines (incl. unit tests in the modules), integration tests +1453/−2 lines; within one cycle.
- **Order 7b → 7c → 8 → 10 unchanged.** 7c (ReferenceDesignation, Syslog bridge, Generic events) uses the Event writer of 7a only; 8 (consumer, SubscriptionList, SF-107) needs the complete provider; 10 needs the complete API.

### 3. Secrets under `/run/secrets/oi4` (`0318d6f`)

- **GL-ADR-022:** the platform may renew the means of authentication while the application runs. Until now they were read once at `build()`; only the certificate files were re-read before a reconnect.
- **`oec-core`:** `Session::set_credentials` (the next CONNECT uses them; test first).
- **`oec`:** `ConnectionSettings` remembers the container storage (`SecretSource`), `reload_auth()` re-reads `credentials`, `private_key.pem`, `passphrase` and the client certificate with the same rules as `build()`. `runtime::renew_auth` runs before every reconnect: unchanged → nothing; changed → new `Session` credentials and TLS configuration, `info` "the means of authentication were renewed (GL-ADR-022)"; unreadable or refused → the last good values stay, `warn` without values. An explicit `Broker` is not re-read.
- **`FileStore`:** new directories 0700, files 0600 on Unix (the Config table holds sensitive values in clear; the store is the application's own data directory). Existing directories keep their mode.
- **Not done on purpose:** sensitive Config values are not written to `/run/secrets/oi4`; GL-ADR-022 reserves it for the platform's means of authentication (A-105).
- **Tests:** `renewed_secrets_apply_on_reconnect` (temporary container storage against the in-process TLS broker: renewed credentials are used at the next reconnect; credentials that are no base64 or removed keep the last good ones; a private key added with the application certificate wins over the credentials, REQ-MQTT-010), `file_store_is_owner_only`.

## Risks and open technical points

- **SF-107/SF-108** open. SF-107 (writability through the SubscriptionList) would also list the `Set Config` subscriptions; it matters from increment 8.
- **Sensitive values at rest:** the store holds them in clear, protected by file modes only (0600/0700). Encryption at rest is not required by the guideline; a platform can mount the data directory encrypted.
- **Regex dialects:** a pattern using a Rust-only construct may be judged differently by other tools (D7 skips patterns it cannot compile).
- **Handler on the runtime task:** as for `Set Data`, a blocking `on_set` delays the bus loop (documented).
- **D7:** T7-MON-09/13 … 17 still `planned`.
