## Intent

P3 is closed, and the PO order is P4 first, P5 interleaved, P4b/P5b afterwards (C-045 review D-2). The STATUS "Next step" asked for:
- the P4 plan and cycle cut;
- the crate skeleton `oec/sdk/rust`;
- the offline increments 1–3 against the shared test vectors.

**Split (agent decision):** C-046 delivers increments 1–2, and increment 3 moves to C-047. Reason:
- Increments 1–2 need no runtime dependency, and one vector contract covers them. They form a closed review unit: about 2,300 lines of Rust plus the gate.
- Increment 3 brings the first runtime dependencies (serde, serde_json, time, uuid, and jsonschema behind a feature), the full cargo-deny tree, schema embedding via `build.rs` and the largest typed model (all resource payloads). Together with 1–2, the review would grow too large, and a dependency question would block the dependency-free part.

The PO was not asked during the cycle. All open choices are SDK-internal and listed as D-points.

## Work

### JSON export of the vectors (`3f6e0a0`)

`spectool render` now also writes `oec/spec/export/vectors/*.json` (9 files) and `oec/spec/export/matrix/method-resource.json`:
- the same fields as the Go model, plus `$comment` and `source`;
- Go zero values are omitted (`omitempty`), so a missing field means "" / none;
- `render -check` fails when the export is stale;
- `rebaseline` and `review` render it too.

Why: the Rust and C SDKs should not need a YAML parser for their tests.
- `serde_yaml` is archived and published as `+deprecated`.
- D9 would need a C YAML library.
- JSON is already a dev dependency.

The YAML stays the reviewed source. Documented in `oec/spec/README.md` and ADR-0026 §3.

### Gate

`oec/sdk/check.sh` has a new step 0 before the sketch and spike checks:
- `cargo fmt --all --check`;
- `cargo clippy --offline --locked --all-targets -- -D warnings`;
- `cargo test --offline --locked`;
- `RUSTDOCFLAGS="-D warnings" cargo doc --offline --locked --no-deps`;
- `cargo deny check`. If the advisory DB cannot be fetched, the gate falls back to `cargo deny --frozen check` with the cached DB.

`cargo-deny` (installed 0.20.2) is required; without it the gate fails with the install hint.

`oec/check.sh` step 5 is now labelled "sdk/check.sh (Rust SDK, P3 sketches)". The final echo of `oec/sdk/check.sh` is "sdk checks ok".
