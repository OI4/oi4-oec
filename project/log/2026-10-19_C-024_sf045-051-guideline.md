OPC UA fields the receiver does not use; it does not relax any value rule.

Registered as **SF-053** (decided: the PO asked for it) and fixed in A2 by a table with the former use of each id. No protocol change.
- The guideline changes are implemented as in C-020/C-021 (one local commit per finding, register commit, relative-link check, Docusaurus build). No new GL-ADR unless the PO asks for one (SF-045 and SF-052 are candidates, see "Points for the PO").
